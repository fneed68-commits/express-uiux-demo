## ✨ المميزات

- ✅ واجهة عربية احترافية بتصميم RTL
- ✅ إدارة المهام (إضافة/تعديل/حذف)
- ✅ تبديل الثيم (فاتح/داكن) مع حفظ التفضيل
- ✅ CI/CD كامل عبر GitHub Actions
- ✅ نشر تلقائي على Render عند كل push

## 🛠️ التقنيات

| الطبقة | التقنية |
|--------|---------|
| Backend | Node.js + Express |
| Frontend | HTML5 + CSS3 + JavaScript |
| CI/CD | GitHub Actions |
| Hosting | Render |
| Security | Dependabot |
